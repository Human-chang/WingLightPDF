====================================================================
  WingLightPDF — 輕快免安裝PDF檢視與編輯工具（綠色開源版）
  WingLightPDF — Feather-Light Portable PDF Viewer & Editor
====================================================================

【一、軟體特色】
1. 免安裝綠色版：無須安裝 Python 或任何外部套件，解壓縮即可直接使用。
2. 100% 純本機離線運作：絕不連網、不上傳任何檔案，處理公文、地籍圖、工程圖紙與合約最安心。
3. 開放原始碼透明可查：完整 Python 原始碼皆附於本資料夾內的 `source_code\` 目錄中。

【版本選擇】兩個版本的功能完全相同，差別只在文字辨識 (OCR) 引擎：
• 完整版（檔名含 Full，約 300 MB）：內建 RapidOCR PP-OCRv6 辨識模型，
  繁體中文與密集數字表格（例如規範對照表）都能準確辨識。
• 輕量版（檔名含 Lite，約 140 MB）：使用 Windows 內建 OCR，
  一般文字辨識快又準，但密集的數字表格容易漏字。需要 Windows 已安裝「中文(台灣)」的
  光學字元辨識語言（繁體中文 Windows 通常已內建；若未安裝，請到「設定 → 時間與語言 →
  語言與地區 → 中文(台灣) → 語言選項」安裝「光學字元辨識」）。

【二、如何開始使用】
• 直接雙擊本資料夾內的 `WingLightPDF.exe` 即可開啟程式。
• 若要設為電腦預設的 PDF 開啟軟體：
  1. 打開 `WingLightPDF.exe` 後，點擊右上角工具列的「📌 設為預設PDF」按鈕。
  2. 對電腦裡任意一個 `.pdf` 檔案按右鍵 ➔「開啟檔案」➔「選擇其他應用程式」➔ 選取「WingLightPDF — 輕快免安裝PDF檢視與編輯工具」並點選「永遠 (Always)」。

【三、主要功能一覽】
• 極速檢視與導覽：滾輪縮放 (Ctrl+滾輪)、手型平移、深色反相護眼模式 (看圖紙不傷眼)。
• 多 PDF 同視窗分頁 & 自由拖拉拆分/合併（類似 Chrome 瀏覽器）：
  - 工具列內建「🗂️ 多PDF同視窗分頁」開關，可將多個 PDF 顯示在同一個視窗的分頁列中。
  - 【拖出拆成兩個程式】：按住上方某個 PDF 分頁標籤往視窗外拖出放開（或點右上角「↗ 拆出為獨立視窗」），瞬間拆成兩個獨立視窗。
  - 【拖入合併為一個程式】：將 A 視窗的 PDF 分頁標籤直接拖進 B 視窗內放開，即可無損合併回同一個視窗的分頁列中！
• 頁面管理與跨檔/跨分頁拖曳：
  - 左側縮圖列支援拉窄成緊湊的「單欄寬度」，拉寬時則自動切換為「多排並列網格」。
  - 支援單頁與多頁 (Ctrl / Shift 多選) 直接滑鼠拖曳改變頁序。
  - 支援跨視窗或跨分頁（拖著縮圖經過上方分頁標籤即自動切換分頁）互拖頁面插入，或直接把外部 PDF 拖進縮圖列任意位置插入。
  - 支援旋轉、刪除、擷取頁面、多檔合併、拆分檔案。
• 高解析圈選截圖與去背：
  - 以 300~600 DPI 重新從 PDF 底層渲染局部圖面，貼入 Word/簡報絕不模糊。
  - 支援「一鍵去背透明背景 PNG」與「去背 + 線條加深」。
• 標註與常用圖章匣：
  - 加入繁體中文文字（自動內嵌系統字型不亂碼）、加入圖片。
  - 內建「常用圖章/簽名匣」：核准、已審閱、機密、今日日期章，並支援匯入簽名檔自動白底去背收藏（存放於 `stamps\` 資料夾）。
• 工程圖紙比例尺量測：支援兩點比例尺校正、實際距離量測、多邊形面積與台灣坪數換算。
• 雙檔案比對：支援「左右並排同步捲動縮放」與「紅藍疊圖差異高亮比對」。
• 選用按需 OCR 與文字搜尋：
  - 搜尋文字 (Ctrl+F) 預設毫秒級搜尋內嵌文字，絕不自動跑 OCR 拖慢速度。
  - 遇到掃描檔時，可手動點選「🔍 按需 OCR ▾」辨識局部區域、單頁或全部文件，辨識完即可直接全文搜尋，還能將可搜尋文字層永久寫入 PDF！
